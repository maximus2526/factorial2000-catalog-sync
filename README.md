## 📥 Імпорт XML: Prom і фіди постачальників

Плагін працює з **YML-форматом** (той самий XML, що використовує Prom.ua). Тому можна імпортувати:

1. **Власну вигрузку з Prom.ua**
2. **XML-фіди постачальників**, які вони генерують «для Prom», «YML» або як XML-прайс — якщо структура така ж

### Структура, яку очікує плагін

```
yml_catalog → shop → categories + offers → offer
```

Ключові поля `offer`:

| Поле | Призначення |
|---|---|
| `id` | Артикул → SKU у WooCommerce (+ ваш SKU Prefix) |
| `available` | Наявність (`true` / `false`) |
| `group_id` | Група варіацій; без нього — простий товар |
| `name` / `name_ua` | Назва (пріоритет `name_ua`) |
| `description` / `description_ua` | Опис |
| `price` / `oldprice` | Ціна / стара ціна |
| `categoryId` | Прив’язка до `categories` з XML |
| `picture` | URL зображень |
| `param name="…"` | Характеристики / атрибути |
| `vendor` | Виробник |
| `vendorCode` | Код постачальника (для менеджерів при оновленні) |

### Як імпортувати

1. Відкрийте **Імпорт XML**, завантажте `.xml`.
2. Вкажіть унікальний **SKU Prefix** для цього джерела.
3. Оберіть режим: **прості** (без `group_id`) або **варіативні** (з `group_id`; спочатку «Проаналізувати XML»).
4. Після імпорту додайте URL того ж фіду в **Оновлення XML**, щоб синхронізувати ціни й наявність.

## 💰 Коригування ціни постачальника (маржа / націнка / фіксована сума)

Для кожного з 5 джерел XML у вкладці **«Оновлення»** під чекбоксом **«Не оновлювати ціну N»** доступний перемикач коригування ціни. Поле з'являється, тільки якщо оновлення цін для цього постачальника **дозволено** (чекбокс вимкнений).

Доступні 3 режими:

| Тип | Формула | Додати/Відняти |
|---|---|---|
| **Націнка (%)** | `ціна = закупівельна × (1 ± %)` | так |
| **Маржа (%)** | `ціна = закупівельна / (1 − маржа/100)` | ні (лише збільшує ціну, 0–99%) |
| **Фіксована сума** | `ціна = закупівельна ± сума` | так |

Значення завжди невід'ємне (мінімум `0`). Для «Маржі» перемикач «Додати/Відняти» приховується — маржа за визначенням не може бути від'ємною. Розрахунок виконується на основі ціни **з поточної вигрузки XML**, а не старої ціни в магазині, тож коригування завжди актуальне.

## 🔔 Налаштування Telegram-сповіщень

Плагін може надсилати у Telegram звіти про завершення імпорту та оновлення залишків (скільки товарів оновлено, скільки не знайдено тощо). Це **необов'язково** — якщо поля порожні, нічого не надсилається.

Щоб увімкнути сповіщення, у вкладці **«Оновлення»** треба заповнити два поля.

### 1. Telegram Token ID — токен вашого бота

Токен — це «ключ доступу» до вашого бота, через який плагін надсилає повідомлення.

1. У Telegram знайдіть бота **[@BotFather](https://t.me/BotFather)**.
2. Надішліть команду `/newbot`.
3. Вкажіть назву бота та його username (має закінчуватися на `bot`).
4. BotFather у відповідь надішле токен виду:
   ```
   1234567890:ABCdefGHIjklMNOpqrsTUVwxyz1234567890
   ```
5. Скопіюйте **весь рядок** і вставте у поле **Telegram Token ID**.

### 2. Telegram User IDs — куди надсилати

Це числовий ID чату (або кількох), у який бот надсилатиме звіти.

1. У Telegram знайдіть бота **[@userinfobot](https://t.me/userinfobot)** і натисніть **Start** — він покаже ваш числовий **Id** (наприклад `123456789`).
2. Вставте це число у поле **Telegram User IDs**.
3. Якщо отримувачів декілька — перелічіть їхні ID **через кому**: `123456789, 987654321`.

> ⚠️ **Важливо:** перш ніж бот зможе вам написати, **ви маєте першим написати своєму боту** команду `/start` (або додати бота в потрібну групу). Інакше Telegram заблокує повідомлення і сповіщення не дійде.

Для надсилання в **групу** додайте бота в групу та використайте ID групи (від'ємне число, наприклад `-1001234567890`) у полі User IDs.
